# Hardware Specifications Reference

**Orange Pi 5 Max Specs:**
- **SoC**: Rockchip RK3588
- **CPU**: Quad-core Cortex-A76 @ 2.4GHz + Quad-core Cortex-A55 @ 1.8GHz
- **GPU**: Mali-G610 MP4
- **NPU**: 6 TOPS AI performance
- **RAM**: 10GB or 16GB LPDDR5
- **Storage**: eMMC slot, microSD slot, M.2 M-Key (PCIe 3.0 x4)
- **Display**: 2x HDMI 2.1 (up to 8K@60fps)
- **USB**: 2x USB 3.0, 2x USB 2.0, 1x USB-C (DP Alt Mode)
- **Network**: Gigabit Ethernet, WiFi 6, Bluetooth 5.0
- **Power**: USB-C PD, 5V/4A minimum
